# 문서 패키지 확인 기록

2026-11-11 · `evidence-priority-v1`

이번 확인은 문서와 양식의 정합성 검사다. 새 과제의 모델 동작이나 사람 평가 결과를 측정한 것이 아니다.

| 확인 항목 | 결과 |
|---|---|
| 판정과 연구 범위 | 현재 근거에 따른 관찰 우선순위로 통일. 4주 미래 정답 기준 없음 |
| 비교 조건 | 같은 후보·근거·출력 형식, 모델 내 동일 설정·출력 예산 |
| 지표와 분모 | 전체 시도·미호출·기술 실패·미평가를 구분. 분모가 없으면 해당 없음 |
| JSON 빈 양식 | 6개 파싱 및 과제 버전 확인 |
| 문서 연결 | 새 패키지와 연구 첫 페이지의 상대 파일 링크 존재 확인 |
| draw.io | 두 페이지 XML 파싱, 도형·텍스트 개별 편집 요소 확인 |
| 미리보기 | 시스템·평가 PNG 육안 확인 및 텍스트 폭·페이지 경계 검사 |
| 과거 기록 보존 | 기존 실행기·입력·v1/v2 프롬프트·출력·점수·비용 파일 변경 없음 |
| 이전 첫 페이지 보관 | README·노션 원문의 보관 사본 대조 |
| 저장소 문서 검사 | git diff --check 통과 |

PNG는 draw.io와 같은 좌표·문구 정의에서 생성한 미리보기다. draw.io 앱 자체의 화면 캡처나 내보내기로 표시하지 않는다.

새 과제 실행기 연결, 실제 자료의 본 평가, 두 사람의 독립 평가, 자동 집계기는 이번에 구현·실행하지 않았다. 명세의 필수 시나리오는 다음 구현 단계에서 검수할 항목이다. 과거 코드 검사 82개 통과와 이번 문서 검사를 모델의 의미상 검증 통과로 해석하지 않는다.

이번 문서 작업에서 새 유료 모델 호출·GPU 가동은 없었다. 보존한 예산은 총 $5·Claude $2·GPU 누적 2시간이며, 실제 저장 비용까지 새로 조회하거나 청구서를 확정한 기록은 아니다.

# 인터뷰에서 도출한 검토 가설 초안

2026-11-12 · 상태: **사람 검토 전** · 이 표는 실증 결과나 확정 판단 규칙이 아니다.

사용자 제공 전사문을 읽고 트렌드 탐지·검증과 관련된 논의만 요약했다. 발화자 구분과 자동 전사 정확성이 보장되지 않으며 여러 논의가 섞여 있다. 아래 문장은 연구자가 정리한 해석이지 특정 발화자의 직접 인용이 아니다. 비율·가격 예시를 모집단 통계나 고정 임계값으로 옮기지 않는다. 다른 팀의 주제, 개인 일화, 식별 정보, 무관한 발화는 제외했다.

## 검토 가설과 조사 질문

| ID | 전사문에서 파악한 문제 맥락 | 검토 가설 | 당시 자료에서 확인할 질문 | 적절한 근거와 한계 |
|---|---|---|---|---|
| H1 | 취향·관심 수준·연령·성별에 따라 유행으로 받아들이는 대상이 다를 수 있음 | 일부 집단의 관심을 목표 집단 전체의 확산으로 해석하면 과대 판단할 수 있다 | 관측 집단은 누구이며 한국 20대 남성이라는 대상과 어떻게 겹치는가? | 연령·성별·지역 조건이 명시된 관측, 표본 범위. 미확인 기사나 인플루언서 사례는 목표 집단의 직접 반응이 아님 |
| H2 | 관심이나 검색이 있어도 가격·가용성 등 때문에 실제 선택으로 이어지지 않을 수 있음 | 관심 증가와 실제 채택 사이에 차이가 있을 수 있다 | 검색·클릭 외에 착용·구매를 직접 뒷받침하는 자료가 있는가? 가격·가용성은 어떤 맥락인가? | 자료가 실제 측정하는 행동, 당시 가격·판매 가능 여부. 검색을 구매량으로 바꾸거나 가격만으로 수요를 단정하지 않음 |
| H3 | 미디어 반복 노출, 브랜드 간 유사 디자인, 바이럴이 유행의 인식에 영향을 줄 수 있음 | 게시물 수의 증가가 독립적인 채택인지 같은 홍보의 반복인지 구별해야 한다 | 원생산자·캠페인이 겹치는가? 다른 출처에서 새로운 관측이 있는가? | 원출처·재게시·캠페인 관계와 서로 다른 시점 관측. 홍보가 있다는 사실만으로 기각하지 않음 |
| H4 | 계절·날씨·생활 필요로 구매하거나 관심을 갖는 경우가 언급됨 | 신호를 계절성이나 당시 생활 맥락으로 설명할 수 있는지 확인해야 한다 | 같은 시기 반복되는 관심인가? 당시 기후·행사·착용 목적이 대안 설명이 되는가? | 비교 가능한 과거 구간과 당시 맥락. 계절성을 검토했다는 이유만으로 신호를 자동 무효화하지 않음 |
| H5 | 낯선 스타일의 익숙함·일상 착용 가능성과 유행 인식이 논의됨 | 선도 집단의 주목과 일반적인 일상 채택 사이에 차이가 있을 수 있다 | 관찰된 것은 소개·화제인가, 반복 착용이나 사용 맥락인가? 그 대상은 누구인가? | 당시 구체적 착용·사용 관측과 조사 범위. 외모·취향의 가치 판단이나 ‘무난함’의 임의 점수로 대체하지 않음 |

같은 근거가 여러 가설에 관계될 수 있다. 그 경우 근거를 중복된 독립 관측처럼 세지 않는다. H1~H5는 모든 후보에서 반드시 충족해야 하는 체크리스트나 가중 점수가 아니다. 후보에 맞지 않는 가설은 해당 없음을 설명한다.

## 사람 검토 후 고정하는 절차

1. 원문 접근 권한이 있는 검토자가 해당 논의 구간과 요약을 대조한다. 불명확한 구간은 확정하지 않는다.
2. [인터뷰 해석 검토표](forms/WORKSHEETS.md#인터뷰-해석-검토)를 이용해 해석 수정·채택·제외·보류와 이유를 남긴다. 발화자의 신원이나 민감한 원문은 공개 자료에 복사하지 않는다.
3. 채택한 가설은 `reviewed=true`, 출처 구간을 찾을 수 있는 비공개 `source_ref`, 가설·질문·예상 근거 종류를 함께 고정한다. 해시와 검토 기록을 남긴다.
4. **검토 완료는 가설의 사실성 입증을 뜻하지 않는다.** 전사문 해석을 확인했다는 뜻이며, 실제 후보에서는 별도의 당시 근거로 검토한다.
5. 새 후보와 출력 확인 전에 가설 버전을 고정한다. 모델 결과를 본 뒤 유리한 기준으로 수정하면 새로운 개발 버전으로 분리한다.

실제 본 비교는 검토·동결이 끝난 가설을 사용한다. 현재 로컬 합성 예제의 `reviewed=false` 가설은 연결 동작 점검용이다. 이를 적용하는 진단 출력은 `applied_as_hypothesis`로만 표시한다.

## 비교군 격리

`with_interview`에는 고정된 가설을 주고 자료와 연결하도록 한다. `without_interview`에는 가설 내용·ID·해설·적용 양식·이전 조건의 답을 보내지 않는다. 전사문이나 가설을 검색 자료집에도 넣지 않는다. 공통 목표 집단, 출처·시간 검수 규칙, 검색 한도, 반증 절차는 두 조건에서 유지한다. 평가자가 사실과 반대 근거를 판독할 때 인터뷰 가설에 대한 동의 자체를 정답으로 삼지 않는다.

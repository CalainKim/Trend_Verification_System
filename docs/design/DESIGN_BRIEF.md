# 트렌드 모니터 화면 설계 브리프

Claude Design 에 그대로 붙여넣는 용도. 숫자는 전부 2026-11-02 기준 실제 수집 DB 에서 뽑았다.
원본 값은 같은 폴더의 `mock-data.json`.

---

## 1. 무엇을 만드나

패션 MD 와 바잉 담당자가 쓰는 B2B 트렌드 모니터. 증권 터미널처럼 "지금 뜨는 것" 을 한눈에 보고,
항목을 누르면 근거와 관련 상품이 나오고, 그 판단이 나중에 맞았는지까지 추적되는 화면.

- 사용자: 무신사 같은 패션 플랫폼의 MD, 트렌드 분석 담당자
- 갱신 주기: 하루 1~2회 (실시간 틱 아님). 화면 상단에 "마지막 갱신 시각" 과 새로고침 버튼
- 한 줄 가치: **"뜨는 속성을 먼저 보여주고, 그 판단이 버텼는지까지 채점해 보여준다"**

## 2. 핵심 개념 (화면에 꼭 반영)

| 용어 | 뜻 |
|---|---|
| 속성 | 트렌드의 단위. 상품명에서 뽑은 키워드 (와플, 터틀넥, 크루넥, 하프집업 ...). 74종 |
| 커머스 신호 | 29CM 상의 랭킹 TOP100 안에서 그 속성을 가진 상품 수와 순위 변화 |
| 검색 신호 | 구글 트렌드 한국/미국 주간 지수 (0~100, 요청 안에서만 비교 가능한 상대값) |
| 해외 선행 | 미국 검색이 한국보다 먼저 움직였는지 (일 단위 시차) |
| 지속성 판정 | "이 상승이 확인 기간(7일/28일/84일) 뒤에도 절반 이상 남을까?" 지속 / 소멸 / 보류 |
| 검증 결과 | 확인 기간이 지나면 실제로 버텼는지 자동 채점. 맞음 / 틀림 |
| 기저율 | 전부 "지속" 이라고 찍었을 때의 정확도. 29CM 7일 기준 54.1%. 정확도는 항상 이것과 나란히 표시 |

판정은 두 단계로 보인다: **지금 = 예측(판정과 근거)**, **나중 = 채점(맞음/틀림)**.
이게 이 제품의 신뢰 근거이므로 목록과 상세 모두에서 상태가 보여야 한다.

## 3. 화면 (3장)

### 화면 C. 검증 기록 (모니터링)

판정이 실제로 맞았는지 쌓이는 장부. 증권 앱의 "체결 내역" 같은 위치.

- 상단: 정확도 vs 기저율, 커버리지 (보류 제외 비율), 표본 수. 벤치마크별 탭 (29CM 7일 / 검색 한국 28일 / 검색 3개 지역 84일). **세 벤치마크 점수를 합치지 않는다**
- 표: 상품/속성, 상승 구간 순위 (예: 46 → 18), 확인 시점 순위, 결과 (유지/소멸/이탈), 판정, 맞음/틀림
- 실제 예시 (10/18 → 10/25 상승, 11/01 확인)

| 상품 | 10/18 | 10/25 | 11/01 | 결과 |

| [2PACK] 수피마 코튼 티셔츠 | 46 | 18 | 9 | 유지 |
| Wool tencel round Tee (Ivory) | 20 | 9 | 3 | 유지 |

## 4. 디자인 방향

- 정보 밀도가 높은 업무 도구. 장식보다 정렬된 숫자 (tabular-nums), 얇은 구분선, 작은 상태 칩
- 다크 테마 기본, 라이트 테마도 지원
- 상승/하락 색은 한국 증권 관례 (상승 빨강, 하락 파랑)를 따르되, 색만으로 구분하지 않도록 화살표 같이 표기
- 판정 상태 칩: 지속 / 소멸 / 보류 / 채점 대기 / 맞음 / 틀림 을 색과 아이콘으로 구분
- 언어: 한국어. 속성명과 상품명은 원문 그대로
- 데스크톱 1440px 기준, 태블릿에서 표는 가로 스크롤

## 5. 지켜야 할 데이터 규칙 (화면에 틀린 해석이 나오지 않게)

1. 검색 지수는 절대량이 아니라 상대값이다. 서로 다른 속성의 지수를 같은 축에서 크기 비교하지 않는다. 같은 속성의 한국/미국, 같은 속성의 시점 간 비교만 한다
2. 정확도에는 항상 기저율을 함께 표시한다
3. 보류는 오답이 아니다. 커버리지로 따로 보여준다
4. 29CM 와 무신사는 같은 계열이라 독립 채널 두 개로 세지 않는다. 화면의 "확인 채널 수" 에 둘을 따로 세지 않는다
5. 데이터 출처와 마지막 수집 시각을 항상 화면에 둔다
6. 검색 지수 0 은 결측일 수 있다. 0 으로 그리지 말고 끊어서 그린다

## 6. 아직 없는 것 (자리만 잡기)

- 판정 모델 (Claude) 연결 전이라 판정 칩과 근거는 예시
- 인구통계 리프트, 해외 선행 일수 값은 파이프라인에 계산 코드가 있으나 이 데이터에는 아직 안 뽑음
- 무신사 랭킹 (수집 허가 대기)

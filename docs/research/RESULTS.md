모델별 토크나이저와 추론 설정이 달라 같은 토큰 수를 같은 계산량으로 해석하지 않는다. 요청 시간은 준비 시간을 제외한 클라이언트 관측값이다. 8건의 작은 배치에서는 GPU 준비 시간이 비용에 크게 영향을 준다.

기존 Pod의 GPU가 사용 불가여서 Runpod 자동 이전으로 같은 A40를 사용했다. **실험 후 기존 Pod와 이전된 Pod 모두 시간당 $0.00의 중지 상태를 확인했다.** 가중치는 기존 Global volume에 남아 있어 보관료는 계속될 수 있다. 임대 기록은 [비용 JSON](pilot-costs.json)에 있다.

- **Qwen — HOLD:** 후속 7개 관측일의 실제 순위가 없으므로 판단할 수 없다고 응답했다. 실제 미래값을 숨긴 것은 의도된 설계다.

AI 보조 내용 점검에서는 Claude의 지지·반대 근거 객체 34개 중 구간·개수 오류가 있는 3개와 필요조건을 과장한 추가 2개를 찾았다. Qwen은 6개 객체 중 1개에서 **확인 문턱을 미래 평균처럼 사용하고 근접한 수치라는 이유로 이상 조건을 충족한다고 판단**했다. 두 오류 건수는 발언량과 보류율이 달라 그대로 모델 순위에 사용할 수 없다. 사람 평가자 합의 결과나 완전한 환각률도 아니다.

정식 비교 범위, 평가 기준, 추가 자료 수집과 논문 방향은 이후 논의한다. 기존 A/B/C·상의 확장·새 시점 검증 제안은 확정 일정이 아닌 후보 초안이다. 이번 원인 점검에서는 프롬프트를 바꾸거나 추가 호출하지 않았다.

# 복사해서 쓰는 검토·평가표

빈 작성 양식이다. 사실·가설·모델 제안·사람 판정·미래 후속 관측을 구분한다. 자세한 선택지와 분모는 [양식 안내](README.md), [평가 명세](../EVALUATION.md)에 있다.

## 인터뷰 해석 검토

원문을 볼 수 있는 검토자가 작성한다. 개인 신원이나 민감한 발화를 공개 양식에 복사하지 않는다.

| 가설 ID | 접근 가능한 비공개 원문 구간 | 현재 해석 | 채택·수정·제외·미해결 | 수정 내용·이유 | 검토자·확정 시각 |
|---|---|---|---|---|---|
| | | | | | |

채택한 가설도 실제 후보의 사실 근거가 아니다. 후보별 자료에서 지지·반대·해당 없음을 다시 검토한다.

## 최초 평가와 합의

| 항목 ID | 평가자별 최초 값 | 최초 일치 여부 | 합의 값/미해결 | 이유·근거 |
|---|---|---|---|---|
| | | | | |

최초 기록 파일과 합의 기록 파일의 해시·확정 시각을 별도로 남긴다. 합의 후 값으로 최초 일치도를 계산하지 않는다.

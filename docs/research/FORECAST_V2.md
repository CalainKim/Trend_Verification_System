# 예측·보류 기준 v2 — 1차 동작 확인

2026-11-08 · 이번 주 결정 사항 · 정식 연구 설계와 성능 평가는 별도

## 결정한 목적과 범위

판단 시점까지 확보한 과거 순위로 **이후 수집이 있는 7개 관측일의 상승 지속성을 예상**한다. 미래값을 받아 사후 판정식을 계산하는 작업이 아니다. 이번에는 수정된 과제 지시를 Qwen이 의도대로 수행하는지만 확인한다.

기존과 동일한 맨투맨 8상품, 14개 과거 관측과 계산 특징, Qwen3-8B 가중치·추론 설정을 사용한다. **사용자 JSON은 그대로 두고 시스템 지시만 `forecast-v2`로 교체**한다. 사례별 정답이나 권장 답변을 넣지 않는다. 이번 호출은 Qwen 8회, 재시도 0회이며 Claude는 호출하지 않는다.

## 예측과 보류 기준

| 출력 | 이번에 정한 의미와 조건 |
|---|---|
| WATCH | 과거 자료에서 상승분 절반 이상 유지 쪽이 더 지지된다는 예측 |
| NOT_SUPPORTED | 과거 자료에서 그 기준 미달 쪽이 더 지지된다는 예측 |
| HOLD — 자료 문제 | 필요한 과거 순위·시점이 없거나 손상·모순돼 흐름을 해석하기 어려움 |
| HOLD — 방향 불명확 | 과거 관측의 한계 또는 서로 반대되는 신호를 구체적으로 대조해도 어느 방향이 더 지지되는지 정하기 어려움 |

미래 실제값 부재, 100% 확신 부재, 광고·리뷰 등 이번 범위 밖의 정보 부재만으로 보류하지 않는다. 순위 변동이나 목록 부재 하나만으로도 자동 보류하지 않는다. HOLD는 사용한 과거 근거와 왜 방향을 정하기 어려운지를 설명해야 한다. 무조건 두 방향 중 하나를 고르게 하는 규칙은 아니다.

평가 문턱은 **미래 평균이 이 값 이내이면 지속으로 볼 기준**이다. 미래의 관측값이나 이미 산출된 예측값이 아니다. 모델은 이를 미래 평균으로 대입하지 않고, 별도의 미래 순위 숫자를 만들 필요도 없다. 목록 부재의 101 역시 실제 순위가 아닌 계산 경계값으로 구분한다.

## 입출력 계약

- 입력: 상품 정보, 판단 시점, 과거 14개 관측, 같은 관측으로 계산한 평균·상승폭·문턱, 근거 ID.
- 출력: `verdict`, `summary`, `support`, `against`, `unknowns`의 기존 다섯 필드.
- `summary`: 예측임을 명시하거나 구체적인 과거 자료 기반 보류 사유를 기록한다.
- `support` / `against`: 최종 선택과 관계없이 지속을 지지하거나 반대하는 과거 관측·해석을 근거 ID와 연결한다.
- `unknowns`: 과거 자료의 부족과 관측 한계를 기록한다. 미래 정답을 요구하지 않는다.
- v1 실행·프롬프트는 보존하고 v2는 별도 저장소에 기록한다. 버전이 다른 실행을 같은 저장소에서 이어 쓰지 않는다.

## 이번 출력 확인 기준 — 정답률 채점 없음

| 점검 | 확인 방법 |
|---|---|
| 미래값 요구 | 미래 실측이 없다는 사실만으로 예측을 중단했는가? 단순 한계 언급과 구분한다. |
| 문턱 혼동 | 판정 문턱을 실제 미래 평균이나 독립적으로 산출한 예측 평균처럼 사용했는가? |
| 미래 사실 생성 | 주지 않은 미래 순위·수집 날짜를 관측 사실로 만들었는가? |
| 과거 근거 사용 | 예측 또는 허용된 HOLD 이유를 실제 과거 관측과 연결했는가? |
| 설명 품질 | 숫자·구간·관측 상태 오류가 있는가? 과제 이해 여부와 별도로 기록한다. |

WATCH 증가나 HOLD 감소 자체를 성공 기준으로 쓰지 않는다. 각 사례를 읽어 미래 예측 역할을 수행했는지 확인한다. 정답을 이미 확인한 개발 사례의 재실행이므로 독립 평가나 정확도 개선의 근거가 아니다. 정식 연구 질문·본 비교·논문 결론은 이후 결정한다.

## 예산과 실행 통제

기존 기록의 Claude $0.101140과 GPU 추정 $0.147667(886초)을 누적 계산에 포함한다. 이번 GPU 세션 상한은 30분이며 기존 사용 시간과 합쳐 2시간 미만이다. 시간당 $0.60을 기준으로 이번 상한까지 사용해도 API·GPU 누적 약 $0.549, 저장·IOPS 여유분 $0.50을 더해 약 $1.049로 총 $5 안이다. 이는 청구서가 아닌 실행 상한 계산이며 실제 종료 시각과 비용 추정은 실행 후 기록한다.

이번 요청은 8회만 실행하고, 완료 응답은 반복하지 않는다. 기술 실패가 발생하면 그 기록을 남기며 자동 재시도하지 않는다. GPU는 출력 확보 직후 중지한다.

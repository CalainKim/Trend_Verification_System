# 연구 실행의 운영 제약

2026-11-11 · 운영 관리용이며 논문의 연구 질문·평가 지표·결과표에 포함하지 않는다.

연구 평가는 방법론과 논리적 타당성에 한정한다. 비용, 실행 속도, 사용 토큰, GPU 사용 시간으로 모델이나 방법의 우위를 판단하지 않는다. 재현에 필요한 모델·설정·최대 출력 길이와 기록 시각은 통제 정보로 보존한다.

사용자가 이전에 정한 추가 지출 총 $5, Claude 최대 $2, GPU 누적 2시간 한도는 유지한다. 연구 지표에서 비용을 제외한 것이 추가 지출 허가나 기존 한도 초기화를 뜻하지 않는다. 이번 문서 변경에서 새 모델 호출·GPU 가동은 없다.

과거 [v1 비용 기록](pilot-costs.json)과 [v2 비용 기록](forecast-v2-costs.json), 실행기 과금 방지·중복 호출 방지 기능은 수정하거나 삭제하지 않는다. 기존 파일의 수치는 당시의 운영 추정이며 새 연구의 결과가 아니다. 저장·IOPS 등의 현 청구 상태를 이번 작업에서 새로 확인하지 않았다.

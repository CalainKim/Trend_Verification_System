# 복사해서 쓰는 사람 평가표

이 양식은 비어 있다. 실제 모델 출력이나 평가 결과가 아니다. 필요한 표를 노션·문서에 복사하고 행을 추가해 작성한다. 빈칸은 ‘아직 작성하지 않음’이며 ‘오류 없음’이나 0점이 아니다.

**순서:** 두 사람이 각각 근거 기준표 작성 → 기준표 합의 → 모델·방법을 가린 출력 각각 평가 → 최초 평가를 보존하고 합의표 작성. 상대방의 평가를 보기 전에 자신의 독립 평가를 확정한다. JSON 보관 양식과 자세한 기준은 [사용 안내](README.md), 수식은 [평가 명세](../EVALUATION.md)에 있다.

## 1. 모델 출력 전 근거 기준표

한 후보·한 판단 시점마다 두 사람이 각각 작성한다. 이 단계에서는 모델 답변을 보지 않는다. 대상 집단과 수치를 원자료보다 넓게 해석하지 않는다.

| 기본 정보 | 작성란 |
|---|---|
| 기준표 ID / 작성자 ID | |
| 작성일·시간대 | |
| 후보 이름·정의 / 사례 ID | |
| 판단 시점 | |
| 목표 집단 / 실제 자료의 집단 범위 | |
| 근거 묶음 링크·파일 / 해시 | |
| 작성 전 모델 출력 열람 여부 | |
| 독립 기준표 확정 시각 | |

### 확인 가능한 사실

| 항목 ID | 사실 한 가지 | 근거 ID와 원문 위치 | 지표·단위·기간·대상 범위 | 주의할 점 |
|---|---|---|---|---|
| | | | | |
| | | | | |

### 중요한 반대 근거

무시하면 판정이나 주요 설명이 달라질 수 있는 반대 관측·대안 설명을 적는다. 실제 근거가 없으면 억지로 만들지 않는다.

| 항목 ID | 반대 관측 또는 대안 설명 | 근거 ID와 원문 위치 | 판정에 중요한 이유 |
|---|---|---|---|
| | | | |
| | | | |

### 미확인 정보와 출처 관계

| 항목 ID | 모르는 정보·출처 관계 | 판단에 필요한 이유 | 확인할 자료·관측 |

## 2. 모델 출력을 본 뒤의 독립 평가표

모델명·방법명·호출 순서 없이 평가한다. 아래에는 임의 출력 ID만 적는다. 요약문에 있는 사실도 평가하고, 같은 사실의 반복은 한 번만 센다. 인용 ID가 존재하는 것과 내용이 주장을 뒷받침하는 것은 별개다.

| 기본 정보 | 작성란 |
|---|---|
| 평가 기록 ID / 평가자 ID | |
| 작성일·시간대 / 독립 평가 확정 시각 | |
| 사례 ID / 임의 출력 ID | |
| 근거 묶음 링크·해시 | |
| 합의 기준표 링크·해시 | |
| 출력 원문 링크·해시 | |
| 실행 상태: 유효 / 형식·ID 오류 / 잘림 / API 실패 | |
| 의미 평가 가능 여부와 불가능한 이유 | |

### 사실과 해석

사실의 선택지는 **뒷받침됨 / 뒷받침 안 됨 / 근거와 모순 / 자료로 확인 불가 / 미평가**다. 해석 문장은 별도로 표시하고, 제공 근거보다 과한 결론인지 적는다.

| 항목 ID | 출력 위치·주장 | 사실 또는 해석 | 평가 | 근거 ID·원문 위치와 이유 |
|---|---|---|---|---|
| | | | | |
| | | | | |
| | | | | |

### 중요한 반대 근거 반영

기준표의 중요 반대 근거를 빠짐없이 옮긴다. 선택지는 **적절히 반영 / 누락 / 왜곡 / 미평가**다. 단순 언급만으로 적절히 반영했다고 표시하지 않는다.

| 기준표 반대 근거 ID | 평가 | 출력에서 다룬 위치 | 그렇게 평가한 이유 |
|---|---|---|---|
| | | | |
| | | | |

### 전제와 판정의 논리적 연결

모델이 실제로 쓴 짧은 설명만 대조한다. 선택지는 **연결이 타당함 / 연결이 부적절함 / 미해결 / 평가 불가**다. 참인 수치를 인용해도 그 수치에서 결론이 나오지 않으면 논리적 연결은 부적절할 수 있다. 내부 사고 과정을 추정해 채우지 않는다.

| 확인 항목 | 출력 위치·근거 ID | 평가·이유 |
|---|---|---|
| 어떤 전제가 어떤 해석·판정을 뒷받침하는가 | | |
| 근거에 없는 도약 또는 대상·시점 범위 이동이 있는가 | | |
| 결론을 전제로 반복하는 순환논증이나 자기모순이 있는가 | | |
| 중요한 반대 근거가 최종 판단에 어떻게 반영되었는가 | | |
| 논리적 연결의 종합 판독과 미해결 사항 | | |

### 판정과 오류

| 확인 항목 | 평가·답변 | 근거 ID·출력 위치와 이유 |
|---|---|---|
| 중대한 오류 유무: 있음 / 없음 / 미확정 | | |
| 오류가 있다면 종류와 판단에 미친 영향 | | |
| 판정 적절성: 적절 / 부적절 / 미해결 / 평가 불가 | | |
| HOLD일 때만: 보류 적절성. HOLD가 아니면 해당 없음 | | |
| 추가 확인 조건이 구체적이며 관측 가능한가 | | |
| 아직 읽지 않거나 판단하지 못한 항목 | | |
| 독립 평가 완료 여부 | | |

모든 판정에 대해 판정 적절성을 평가한다. HOLD 전용 항목만 비-HOLD 출력에서 해당 없음으로 둔다. 읽을 수 있는 기술 실패 원문은 진단할 수 있지만 유효 판정으로 바꾸지 않는다. 원문 자체가 없거나 읽을 수 없으면 의미 평가 불가로 기록한다.

## 3. 독립 평가 후 합의표

최초 기록은 덮어쓰지 않는다. 두 사람이 무엇에 동의했는지와 합의하지 못한 내용을 구분한다. 기준표 합의와 출력 평가 합의는 이 표를 각각 복사해 작성한다. 출력의 사실 주장은 원문 위치와 동일 명제로 대응시킨 뒤, 일대일 대응되고 두 사람이 평가를 확정한 항목만 최초 일치도에 넣는다. 분할·병합 차이를 최초 평가에 소급 적용하지 않는다.

| 평가자 1 주장 ID | 평가자 2 주장 ID | 원문 위치·같은 원자 주장인지 | 최초 일치도 비교 가능 여부 | 분할·병합·미대응 사유 |
|---|---|---|---|---|
| | | | | |

| 기본 정보 | 작성란 |
|---|---|
| 합의 기록 ID / 작성일·시간대 | |
| 대상: 근거 기준표 또는 출력 평가 | |
| 사례 ID / 출력 평가라면 임의 출력 ID | |
| 평가자 1의 원본 기록 링크·해시 | |
| 평가자 2의 원본 기록 링크·해시 | |
| 합의본 링크·해시 / 확정 시각 | |

| 항목 ID | 평가자 1 최초 값 | 평가자 2 최초 값 | 최초 일치 여부 | 합의 값 또는 미해결 | 근거·이유 |
|---|---|---|---|---|---|
| | | | | | |
| | | | | | |
| | | | | | |

## 4. 집계로 옮기기 전 확인

- 전체 사례 분모 `N`은 **각 모델·방법에서 실제 첫 호출을 시도한 사례 수**다. 미실행은 따로 기록한다. 재시도를 새 독립 사례로 세지 않는다.
- 기술 실패와 의미 평가 미완료를 ‘오류 없음’으로 바꾸지 않는다. 출력 판정의 분포와 실패 수를 함께 남긴다.
- 주장 비율의 분모는 판독한 사실 주장, 반대 근거 비율의 분모는 기준표의 중요 반대 근거다. 사례 수 `N`과 혼용하지 않는다.
- 사실·반대 근거 항목이 없으면 해당 없음, 아직 판독하지 않았으면 미완료로 구분한다.
- 평가자 일치도는 **합의 전 값**으로 계산한다. 합의 후 값이 같아졌다는 사실을 최초 일치도로 보고하지 않는다.
- 준비되면 [집계 양식](review-summary.template.md)에 분자·분모와 미평가 수를 함께 적는다. 현재 양식 자체에는 측정값이 없다.

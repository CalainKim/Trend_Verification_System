# 시계열 근거 구성에 따른 패션 상품 상승 지속성 판단: LLM 예비 연구

2026-11-08 초안 골격. 실험 수치는 검증된 결과 파일에서만 채운다.

## 초록

패션 상품의 순위 급상승은 후속 관측에서도 유지되는 상승과 짧게 끝나는 상승을 함께 포함한다. 본 연구는 상품 순위의 지속성을 판단할 때 LLM에 제공하는 시계열 근거 구성의 영향을 조사한다. 현재 상태, 원시 순위 이력, 원시 이력과 계산 특징의 세 입력을 정의하고, Claude와 Qwen에서 동일한 질문과 출력 계약으로 비교하도록 설계하였다. 이번 단계는 맨투맨 8상품을 대상으로 계산 특징을 포함한 입력의 실제 실행과 수치 평가를 확인하는 예비 실험이다. 답한 사례의 정확도뿐 아니라 답변율, 지속 적중률·재현율, 근거 연결, 기술 실패, 비용을 함께 기록한다. 최종 결과는 검증된 실행 이후 아래 결과 절에 반영한다. 단일 판단 시점과 제한된 상품 수로 인한 일반화 한계를 명시한다.

## 1. 문제와 관련 연구

프로젝트의 문제 정의는 상승한 상품을 발견한 뒤 이를 관찰·검토할 근거를 모으기 어렵다는 것이다. 제공된 회의 기록에서 모델 고도화 카테고리 한 개 선정과 GPU 확보가 검증 파트의 작업으로 정리되었다. 인터뷰 원문 자체는 이 저장소에서 확인되지 않았으므로 특정 인터뷰 발언을 직접 인용하지 않는다.

LLM의 시계열 활용은 선행 연구가 있는 주제다. 본 연구의 기여 후보는 상용 순위 자료의 제약 아래에서 원시 이력과 계산 특징이 판단·보류·수치 오류에 주는 차이를 투명하게 평가하는 데 있다. 모델 크기나 GPU 종류 자체를 기여로 내세우지 않는다. 근거와 참고문헌은 [프로토콜](PROTOCOL.md)에 연결한다.

## 2. 자료와 정답 정의

29CM 순위 자료에서 기준 7관측일과 감지 7관측일 사이 평균 순위가 10계단 이상 오른 상품을 후보로 삼는다. 후속 7관측일에 상승분의 절반 이상이 남으면 지속으로 정의한다. 수집이 있었던 날의 TOP100 목록 밖은 경계값 101로 취급하며 실제 순위로 해석하지 않는다. 미래 확인 구간은 입력에 포함하지 않는다.

예비 실험은 맨투맨 8상품·7브랜드·2026-10-12의 한 판단 시점이다. 2상품은 동일 계열의 색상 변형이다. 현재 확보한 과거 자료로 판단 시점을 모사했으며 당시 가용 데이터 버전의 완전한 재현을 주장하지 않는다.

## 3. 방법과 비교군

정적 입력 A, 원시 순위 이력 B, 동일 이력과 계산 특징 C를 정의한다. A/B/C 차이와 모델 차이는 별도의 비교 축이다. 이번 예비 실험에서는 C만 실제 호출하며 고정 기준선 두 개와 시계열 기준선 두 개를 함께 채점한다. A/B가 실행되지 않은 상태에서는 시계열 추가의 효과나 특징 계산의 효과를 주장할 수 없다.

모델은 지속(WATCH), 소멸(NOT_SUPPORTED), 보류(HOLD)와 지지·반대 근거 및 부족한 정보를 출력한다. 파싱 실패나 응답 중단은 보류가 아니라 기술 실패로 별도 처리한다.

## 4. 예비 결과

실제 결과와 실행 상태는 [RESULTS.md](RESULTS.md)에 연결한다. 미실행 항목을 0%나 실패로 위장하지 않으며, 정답 해시가 일치하지 않은 결과는 채점하지 않는다.

보고 표에는 N, 답한 수, 정답·오답·보류·실패 수, 답변율, 답한 사례 정확도, 지속 적중률·재현율, 시간, 비용을 포함한다. 답변율과 정확도가 상충하면 두 값을 함께 설명한다. 모델의 근거 중 입력 자료로 지지되는 부분과 검토가 필요한 수치를 사례별로 남긴다.

## 5. 논의와 한계

- 상품 순위의 지속성은 판매 증가·광고 원인·전국적 유행의 직접 정답이 아니다.
- 개발에 사용한 8상품군은 후속 독립 평가에서 제외한다.
- 같은 날짜 상품 간에는 공통 요인이 있고 색상 변형도 있어 독립 표본 가정이 약하다.
- 일부 원본에는 계절성 정보가 없으며 있는 경우도 속성 검색의 간접 지표다. 핵심 비교에서는 이를 제외했다.
- 같은 자료에서 계산한 특징은 새 관측을 추가하지 않는다. C-B는 정보 정리의 효과로 해석한다.
- 반복 호출 수를 새로운 상품 또는 새로운 시점의 수로 세지 않는다.
- 개선이 명확하지 않아도 오류 유형, 보류, 비용과 불확실성을 결과로 남긴다.

## 6. 후속 평가

설정과 프롬프트를 고정하고 기존 상의 자료의 후향적 A/B/C 비교를 수행한다. 이어 신규 시점의 관측 창과 정답이 완성되면 시간에 따른 검증을 추가한다. 후속 호출은 이번 $5 예산에 포함되지 않으므로 현재는 설계와 실행 준비까지만 수행한다.

# 논문 구성 메모 — 연구 방향 미확정

2026-11-08 · 기존 초안의 자료·구성 후보 보관

**이번 주 산출물은 연구 환경과 1차 구현·입출력 스펙 점검이다.** 연구 질문, 본 비교, 평가 기준, 논문 기여와 일정은 이후 결정한다. 이 문서는 확정된 논문 초록이나 결과 결론이 아니다. 기존 실행 설정과 수치 기록은 [실행 설정 기록](PROTOCOL.md)과 [테스트 기록](RESULTS.md)에 보존한다.

## 현재 확보한 자료

프로젝트의 문제 정의는 상승한 상품을 발견한 뒤 이를 검토할 근거를 모으기 어렵다는 것이다. 제공된 회의 기록에서 모델 고도화 카테고리 한 개 선정과 GPU 확보가 검증 파트의 작업으로 정리되었다. 인터뷰 원문 자체는 이 저장소에서 확인되지 않았으므로 특정 인터뷰 발언을 직접 인용하지 않는다.

29CM 순위 자료에서 맨투맨 8상품·7브랜드·2026-10-12의 한 판단 시점을 개발용으로 선택했다. 두 상품은 동일 계열의 색상 변형이다. 현재 확보한 과거 자료로 판단 시점을 모사했으며 당시 가용 데이터 버전의 완전한 재현을 주장하지 않는다.

테스트는 기준 7개 관측일과 감지 7개 관측일 사이 평균 순위가 10계단 이상 오른 상품을 대상으로 했다. 후속 7개 관측일에 상승분의 절반 이상이 남으면 지속으로 분류하는 기존 규칙을 사용했다. 수집 목록 밖에 대입하는 101은 실제 관측 순위가 아니다. 미래 확인 구간은 모델 입력에 넣지 않았다. 이 정의를 논문의 최종 정답으로 채택할지는 별도 결정 사항이다.

## 구현·실행 확인 기록

- Claude API와 A40의 Qwen3-8B를 연결하고, 같은 자료로 각 8회 응답을 저장했다.
- 정적 입력 A, 원시 순위 이력 B, 동일 이력과 계산 특징 C의 입력 생성과 검사를 구현했다. 실제 호출은 C만 수행했다.
- 출력 형식은 지속 예측 `WATCH`, 소멸 예측 `NOT_SUPPORTED`, 보류 `HOLD`와 요약·지지/반대 근거·부족한 정보다. 기술 실패를 보류로 바꾸지 않는다.
- 예측을 봉인하고 공개 예측 커밋을 먼저 남긴 뒤 정답을 복원했다. 원본 139건 정답의 봉인 해시가 일치함을 확인했다.
- 비용·시간·채점 수치와 실제 출력은 재현 가능한 테스트 기록으로 남겼다. 모델 우열이나 시계열의 효과를 판단하는 결론으로 사용하지 않는다.

## 먼저 정리해야 할 과제 전달 문제

Qwen의 보류 7건은 모두 미래 실측이 없다는 사실을 주된 이유로 들었다. 예측하라는 문구는 실제 프롬프트에 있었지만, 미래 정답 부재와 보류할 만한 과거 정보 부족을 충분히 구분했는지 점검이 필요하다. 유일한 WATCH도 평가 문턱을 미래 평균처럼 사용했다.

따라서 응답이 정상 종료되고 JSON이 유효하다는 것만으로 의도한 예측 과제를 수행했다고 볼 수 없다. [프롬프트·실제 출력 진단](QWEN_PROMPT_DIAGNOSIS.md)과 [설명 근거 점검](EVIDENCE_AUDIT.md)에 확인 사실과 원인 가설을 구분해 남겼다. 추가 호출이나 프롬프트 수정 실험은 수행하지 않았다.

## 나중에 결정할 연구 구성 후보

시계열 근거 구성의 효과는 연구 방향 후보 중 하나다. 이를 선택한다면 정적 상태, 원시 이력, 계산 특징의 차이를 분리해서 비교할 수 있다. LLM의 시계열 활용에는 선행 연구가 있으므로 결합 자체나 GPU 종류만을 기여로 내세울 수는 없다. 관련 자료 링크는 [설정 기록](PROTOCOL.md)에 보관한다.

정식 계획을 만들 때는 다룰 문제와 정답의 의미, 과거 입력에 대한 보류 조건, 비교군, 평가 지표, 자료 확장 범위와 독립 검증 방법을 함께 결정해야 한다. 상의 확장과 새 시점 검증은 검토 후보이며 이번 주 확정 일정이나 수행 약속이 아니다.

논문을 작성하게 되면 문제·관련 연구, 자료, 방법, 결과, 한계 순으로 구성할 수 있다. 현재는 환경 및 입출력 명세 점검 기록을 모으는 단계이며, 초록의 성능 주장이나 최종 결론은 작성하지 않는다.

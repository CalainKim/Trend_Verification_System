# 근거 기반 리즈닝 연구의 출처와 자료 용도

2026-11-11 · `evidence-priority-v1` · [교수님 검토용 초안](PAPER_DRAFT.md)

현재 연구의 목표는 확보된 근거를 바탕으로 한 관찰 우선순위 검토다. 아래 기록은 논문에 쓸 수 있는 주장과 자료의 용도를 구분한다. 기존 상품 예측 결과, 설명용 과거 사례, 합성 진단 자료를 새 과제의 본 평가 결과로 합산하지 않는다.

## 1. 선행 연구와 공식 명세

| 출처 | 초안에서 사용하는 내용 | 이 출처로 주장하지 않는 내용 |
|---|---|---|
| [Gao et al. (2023), ALCE, EMNLP](https://aclanthology.org/2023.emnlp-main.398/) | 답변 정확성과 인용 품질을 구분하는 평가 관점 | 우리 판정이 이미 정확하다거나 ALCE 점수를 재현했다는 주장 |
| [Turpin et al. (2023), NeurIPS](https://arxiv.org/abs/2305.04388) | 설명문을 모델 내부 판단 과정의 충실한 기록으로 바로 해석할 수 없다는 한계 | 현재 Qwen의 오류 원인이 해당 연구의 편향 실험과 같다는 주장 |
| [Traub et al. (2024), arXiv:2407.01032](https://arxiv.org/abs/2407.01032) | 보류가 있을 때 답변 범위와 오류를 함께 평가해야 하는 문제 | 현재의 세 범주 출력에서 AUGRC를 계산했다는 주장 |
| [네이버 검색 API](https://developers.naver.com/docs/serviceapi/datalab/search/search.md) | 연령 코드 `3=19~24`, `4=25~29`; 요청 구간의 상대 검색 지수 | `3+4`가 정확한 20~29세라는 주장, 검색 지수가 구매량이라는 주장 |
| [네이버 쇼핑인사이트](https://developers.naver.com/docs/serviceapi/datalab/shopping/shopping.md) | 네이버 검색·쇼핑 영역의 검색 클릭 추이 | 주문·매출·시장 전체 수요의 직접 측정이라는 주장 |

확인 방법: 논문은 학회 공식 페이지 또는 저자 제출 arXiv 페이지에서 제목·저자·연도·초록의 주장 범위를 확인했다. 네이버는 공식 API 명세를 확인했다. 이 단계에서는 논문의 전체 실험을 재현하거나 자동 평가 코드를 실행하지 않았다. 관련 연구의 역할은 평가 설계를 설명하는 것이며 우리 방법의 효과를 대신 입증하는 것이 아니다.

## 2. 저장소 기록과 해석

| 자료 | 위치 | 확인 사실 | 이번 용도 |
|---|---|---|---|
| Qwen 프롬프트 재실행 | [FORECAST_V2_RESULTS.md](../FORECAST_V2_RESULTS.md) | 2026-11-08, 같은 맨투맨 8건; 최소 과제 수행 3/8, 형식·ID 동시 충족 2/8 | 공학적 동작 점검 |
| 실제 8건 출력 | [forecast-v2-outputs.json](../forecast-v2-outputs.json) | 원문·파싱·검증 결과를 별도 보존 | 출력 오류의 재검토 근거 |
| 내용 점검 기록 | [forecast-v2-review.json](../forecast-v2-review.json) | AI 보조 의미 점검이며 사람 평가 합의가 아님 | 기존 오류 유형의 설명 |
| 당시 프롬프트 | [forecast-v2-prompt.json](../forecast-v2-prompt.json) | 실행 전에 고정한 예측 지시 | 이전 과제와 새 우선순위 과제의 구분 |

기존 82개 검사 통과는 입력·실행기·평가 코드의 검사 결과다. 모델의 의미상 동작, 스타일 후보 검토의 타당성, 두 평가자의 일치도를 뜻하지 않는다. 새 `evidence-priority-v1`의 사람 평가·모델 비교 결과는 아직 측정하지 않았다.

## 3. 스타일 자료의 출처와 구분

아래는 원본 작업공간에서 확인한 자료의 저장소 상대 위치다. 일부 자료는 비공개 작업 디렉터리에만 있으며 이 연구 문서 브랜치에 포함되지 않았다. 이를 공개 저장소에 포함된 연구 데이터셋으로 표시하지 않는다.

| 구분 | 원본 위치 | 내용 | 사용 조건 |
|---|---|---|---|
| 실제 저장 파일럿 | `cases/case_pilot_rugby/meta.json` 및 CSV | 럭비티, 판단일 2024-08-04, 검색 3,285행·쇼핑 7,948행이라는 메타 기록 | 자료 형식 예시; 행 수를 독립 사례 수로 세지 않음 |
| 실제 API의 후향적 설명 사례 | `private/monthly-poc/2025-styles-v1/plan.json` 및 원시 응답 | 헨리넥·럭비티·링거티, 초기 구간 2025-03-01~04-30 | 계획 자체에 결과를 알고 고른 설명 사례라고 명시; 독립 평가 제외 |
| 외부 자료의 기존 목록 | `data/cases/monthly-2025.json` | 3스타일 관련 무신사 편집·인터뷰 자료 4건, 발표일 2025-05~09 | 4월 말 판단 입력에는 미래 자료이므로 제외 |
| 합성 자료 | `examples/dual_pipeline/corpus.jsonl` | 다채널 근거 형식을 시험하는 예제 | 미래 필터·중복·대상 오류 진단에만 사용 |
| 실제 상품 단위 연결 예제 | `private/dual_pipeline/imported/commerce_1911054/corpus.jsonl` | 29CM 상품 1개, 원출처군 1개 | 스타일 전체 확산이나 출처 독립성의 근거로 승격하지 않음 |

3스타일의 월별 검색 요청은 `gender=m, ages=[3,4]`, 쇼핑 요청은 `gender=m, ages=[20]`로 기록되어 있다. 성별과 연령을 동시에 지정한 해당 요청을 성별·연령별로 따로 조회한 초기 자료와 혼동하지 않는다. 그래도 검색 19~29세와 목표 20~29세의 차이는 남으며, 검색·클릭 사용자의 조건을 상품 구매자의 조건으로 바꾸어 기술하지 않는다.

## 4. 주장별 사용 경계

| 초안의 주장 | 근거 | 사용 경계 |
|---|---|---|
| 현재 근거에 따른 관찰 우선순위를 연구한다 | 2026-11-11 확정된 연구 범위 | 인터뷰 원문 인용으로 표시하지 않음 |
| Claude/A40 연결과 저장 경로를 확인했다 | 기존 실행 기록 | 새 과제의 종단 실행 완료를 의미하지 않음 |
| Qwen에 지시 수행과 인용 오류가 있었다 | 8건 원문·점검 기록 | 일반 성능이나 인과 효과의 결론으로 확장하지 않음 |
| 사람 두 명이 독립 평가한다 | 새 평가 프로토콜 | 이미 평가했다는 과거형으로 쓰지 않음 |
| 구조적 검토가 도움이 될 수 있다 | 연구 가설 | 효과 검증 전 우수성으로 서술하지 않음 |
| 향후 실제 반응을 기록한다 | 후속 관측 계획 | 기간 미관측을 영구 실패로 해석하지 않음 |

초기 문제 정의와 인수인계 문서의 핵심인 근거 추적성·반증 가능성·판단 일관성을 본 연구의 방법론 평가로 구체화한다. 고정된 GitHub 커밋과 문서별 차이는 [연구 범위 정합성 검토](ALIGNMENT.md)에서 확인한다. 실제 시장 트렌드 판별이라는 더 넓은 목적 전체를 완료했다고 주장하지 않는다.

기술 문서의 구현 여부와 데이터의 측정 여부는 분리한다. 새 과제의 입력·판정·평가 계약이 정해져도, 실행기 통합·신규 자료 모집·사람 평가·본 비교가 완료된 것은 아니다. 논문 결과표의 미측정 항목을 예시 수치나 이전 상품 과제의 점수로 채우지 않는다.

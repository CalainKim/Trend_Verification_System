# 입력 근거와 최종 설명의 일치 여부 점검

이 문서는 **모델에 실제로 제공한 입력과 최종 설명이 맞는지** 점검한 기록이다. 확인 구간 정답, 정답 파일, 채점 결과를 열지 않고 작성했다. 따라서 아래 건수는 지속·소멸 예측의 정답률이 아니며, 잘못된 설명이 반드시 잘못된 최종 예측을 뜻하지도 않는다. 원래 출력·프롬프트·설정은 수정하지 않았다.

## 점검 범위와 집계 방법

- 대상: `private/research-pilot/live/state.json`의 Claude `structured` 입력·최종 출력 8건. Qwen 출력은 아직 이 점검에 포함하지 않았다.
- 비교 자료: 각 출력에 대응하는 `prepared_input`의 원시 14개 순위, 계산 특징, 구간 정의, 목록 부재의 의미와 제한 사항. 저장된 `numeric_flags`도 함께 검토했다.
- **근거 문장 단위**: `support` 또는 `against` 배열의 객체 하나를 1건으로 센다. 한 객체에 여러 문장·숫자가 있어도 분모에서는 한 번만 센다. 지지 근거 15건 + 반대 근거 19건 = **34건**이다.
- 별도로 요약 8개와 `unknowns` 항목 25개를 읽었다. 같은 오류가 요약에 반복되더라도 근거 문장 34건의 오류 수에 다시 더하지 않는다.
- 확인 항목: 숫자·날짜·구간 소속, 개수, 계산값과 비교 방향, 계산 경계값과 실제 관측의 구별, 주장에 포함된 수학적 필요조건, 입력에 없는 사실의 단정. 단순한 미래 전망·확률 표현은 정답 없이 참·거짓으로 분류하지 않는다.
- 이 기록은 자동 숫자 일치 검사와 별도로 수행한 **AI 보조 내용 점검**이다. 사람 평가자의 독립 판정·복수 평가자 합의가 아니며, 모든 사실 오류를 찾았다고 보장하지 않는다. 논문에서 사람 평가 결과로 표기하면 안 된다.

필드 위치의 배열 번호는 0부터 시작한다. 상품 번호 앞에는 공통 사례 접두사 `rise_2026-10-12_29cm_`가 붙는다.

|---|---|---|---|

| T2 | 2824007 · `against[2]` | 기준 구간을 `8일(9/29~10/06)`로 설명한다. | 기준 구간은 9/29~10/05의 **7개 관측일**이다. 10/06은 감지 구간 첫 관측일이다. 진입이 없었던 연속 8개 관측 자체는 맞지만, 이를 기준 구간이라고 부른 부분이 틀리다. |

| L1 | 2824007 · `against[2]` | 문턱 96.0을 충족하려면 목록 진입이 반복되어야 한다고 단정한다. | 앞으로 한 번 66위이고 나머지 여섯 번이 계산 경계값 101이어도 `(66 + 6×101)/7 = 96`으로 충족한다. 두 번 이상 진입이 필수라는 해석은 성립하지 않는다. **T2와 같은 객체이므로 합집합에서 중복 계산하지 않는다.** |

L1~L3의 계산은 **가상의 순위 조합으로 필요조건 주장만 반박한 것**이다. 실제 확인 구간 순위나 미래 재진입 가능성을 안다는 뜻이 아니다. 이 반례 때문에 NOT_SUPPORTED 판정 자체를 오답으로 바꾸지 않는다.

### 모호하거나 별도 주의가 필요한 표현

| 번호 | 상품 · 필드 | 주의점 |
|---|---|---|
| A1 | 2816996 · `against[0]` | 앞에서는 101을 계산용 경계값이라고 설명하지만, 이어 `101위 등으로 크게 오르내려`라고 실제 순위처럼 쓴다. 명시된 경계값 설명이 있으므로 확정 오류와 분리하되, 표현을 일관되게 할 필요가 있다. |
| A2 | 4125187 · `against[0]` | `마지막 이틀 진입`은 마지막 두 관측일인지 마지막 두 진입일인지 모호하다. 진입은 10/10·10/11이며 마지막 관측일 10/12는 부재다. |
| A3 | 4205649 · `against[0]` | 감지 구간의 목록 부재를 설명한 뒤 `29위에서 77위` 변동을 이어 쓴다. 29·77은 모두 기준 구간 값이다. 전체 과거 흐름을 뜻할 수도 있으므로 확정 구간 오류와 분리했지만 구간을 명시해야 한다. |

요약·부족한 정보 영역에서는 다음 두 항목도 확인했다. 이 항목은 위 34건 분모에 넣지 않았다.

- **2816996 요약**: 최근 값으로 6위·28위·19위를 고르고 `계속 목록에 있다`고 썼다. 실제 마지막 세 관측은 **10/10 부재 → 10/11 28위 → 10/12 6위**다. 중간 부재를 생략해 연속 목록 등재처럼 읽힌다.
- **4216006 `unknowns[2]`**: `목록 밖 날의 실제 순위(101위 이하 어디인지)`라는 전제를 둔다. 입력은 일부 수집 목록이 100개 미만일 수 있다고 명시하므로, 목록 부재만으로 실제 순위가 101위 이하라고 범위를 확정할 수 없다.

## 자동 플래그를 그대로 오류 수로 쓰면 안 되는 이유

63개 플래그에는 날짜 `10/11` 또는 조사와 붙은 날짜의 숫자, 목록 내 관측 수처럼 원시 값에서 셀 수 있는 숫자, 문장 끝 마침표·조사에 따른 숫자 추출 차이, 인용한 한 근거에 직접 쓰이지 않았지만 전체 입력에는 존재하는 정의가 섞여 있다. 예를 들어 `0.7143`은 입력과 출력에 모두 있는데도 여러 사례에서 경고가 남았다. `최소 개선폭 10` 역시 입력의 공통 정의에 있다.

반대로 T1의 33위와 T3의 11위는 전체 `rank_history`에 실제 존재하므로 단순 숫자 일치 검사만으로는 **잘못된 구간에 배치한 문제**를 찾기 어렵다. 따라서 자동 플래그는 검토 대상을 찾는 보조 신호로만 사용하고, 63을 수치 왜곡 건수로 보고하지 않는다. 현재 실험의 검사기와 출력은 그대로 보존하며, 향후 날짜·숫자 토큰화와 구간 귀속 검사를 개선할 때 별도 버전으로 기록한다.

## 보고에 사용할 수 있는 결론

Claude의 구조화 입력 8건에서 최종 근거 객체 34개를 입력과 대조했으며, 구간 혼동·개수 불일치 또는 필요조건 과장이 포함된 객체 5개를 확인했다. 요약과 부족한 정보 영역에도 추가로 주의할 표현이 있었다. 평균·상승폭을 입력에 명시해도 **어느 구간의 값인지 유지하고, 확인 문턱을 올바르게 해석하는 문제는 남았다.** 이 결과는 설명 품질의 초기 점검이며, 지속성 예측 성능이나 시계열 결합 효과는 봉인 후 별도 채점·비교로 판단해야 한다.

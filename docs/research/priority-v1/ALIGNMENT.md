# 초기 취지와 현재 연구 범위의 대조

2026-11-11 · `evidence-priority-v1` · 문서 정합성 검토

## 결론

**방법론과 판단 논리를 검증하는 방향은 초기 핵심 취지와 맞는다.** 초기 문서는 판정값 자체보다 근거 추적성, 반증 가능성, 사람이 검토할 수 있는 절차를 강조했다. 이번 연구는 그중 **현재 확보한 근거로 관찰 우선순위를 판단하고 설명하는 절차**를 검증하는 1차 범위로 한정한다.

비용 효율, 처리 속도, 사용 토큰 수는 연구 질문·평가 지표·결과표·모델 선정 기준에서 제외한다. 모델별 설정과 최대 출력 길이는 비교 조건을 맞추는 통제값으로 유지한다. 과거 실행 기록과 [운영 제약](../OPERATIONS.md)은 별도로 보존한다.

## 그대로 같다고 말할 수 없는 부분

1. **전체 제품 목표보다 좁은 범위다.** 초기 자료에는 실제 트렌드와 일시적 관심의 구분, 시장 반응, 신뢰 점수와 사후 검증도 포함된다. 이번에는 점수나 미래 정답을 만들지 않고, 현재 근거에 대한 판단과 설명의 타당성을 평가한다. 전체 사업 문제의 해결을 입증했다고 쓰지 않는다.
2. **별도 반증 호출을 구현한 것은 아니다.** [기존 T3](https://github.com/CalainKim/Trend_Verification_System/blob/8886fa181f314a001b090cdbb24752dd89aedc0b/docs/verification-handoff.md#L501)는 수집과 분리된 반증 단계를 제안한다. 이번 기본 판정/구조적 검토는 같은 근거를 주는 단일 호출 방식의 비교 설계다. T3 전체 구현 완료나 다단계 에이전트의 효과를 주장하지 않는다.
3. **후속 예측 실험은 다른 질문이다.** 상품 순위 상승이 유지되는지와 현재 스타일 근거를 적절하게 해석했는지는 정답 정의가 다르다. 기존 맨투맨 실행과 순위 지속성 결과를 새 과제의 성능으로 합산하지 않는다.
4. **설계 확정과 효과 입증은 다르다.** 현재는 판정 계약·프롬프트·사람 평가 양식·검수 시나리오를 정리했다. 새 스타일 자료의 모집·동결, 실행기 연결, 모델 호출, 두 평가자의 본 평가는 아직 수행하지 않았다.

## 이번 문서에 적용한 결정

- 연구 질문은 근거 오류·논리적 비약 감소, 반대 근거·불확실성 처리, 모델별 공통·상이한 동작을 다룬다.
- 사실 인용의 정확성과 **전제 → 해석 → 판정**의 타당성을 나누어 평가한다. 숨겨진 사고 과정이나 유일한 정답을 복원한다고 표현하지 않는다.
- 논리적 도약·자기모순·순환논증·중요 반대 근거 누락·대상 및 시점 범위 이동을 구체적인 출력 위치와 함께 기록한다.
- 비용 효율과 속도는 연구 결과로 비교하지 않는다. 과거 원자료·실행 로그를 삭제하거나 운영 한도를 해제하지 않는다.
- 미래 반응은 별도 관측으로 남긴다. 임의의 기간 내 유행하지 않았다는 이유만으로 현재 근거 검토를 실패 처리하지 않는다.

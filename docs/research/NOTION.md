# 맨투맨 1차 추론 테스트 · 연구 프로토콜과 예비 결과

실행일 2026-11-08 · 실제 16회 완료 · 예측 봉인과 정답 해시 일치 확인 · A40 중지 완료

[구현체와 결과: 초안 PR #18](https://github.com/CalainKim/Trend_Verification_System/pull/18)

**이번 결과:** 마지막 순위 유지 기준선은 7/8 정답, Claude는 6 정답·1 오답·1 보류, Qwen은 1 오답·7 보류였다. 이번 실험에서는 LLM의 추가 이점을 확인하지 못했다. 방법론·평가 체계를 완성하고 실패 양상을 수치로 확인한 예비 결과다.

## 1. 무엇을 해결하고 검증하나

프로젝트의 문제를 “급상승한 상품이 잠깐 오른 것인지, 이후에도 순위 상승을 유지할지 구분하기 어렵다”로 좁힌다. 맨투맨 8상품으로 방법을 준비하고 기존 상의 자료와 신규 시점으로 확장한다. 인터뷰 원문을 직접 검증한 발언으로 인용하지 않는다.

- RQ1: 현재 상태만 제공할 때보다 과거 순위 흐름을 추가하면 판단이 개선되는가?
- RQ2: 같은 순위 흐름에 코드로 계산한 특징을 추가하면 판단과 수치 해석이 개선되는가?
- RQ3: Claude와 Qwen에서 효과·오류·비용이 어떻게 다른가?

핵심은 **시계열 근거 구성의 효과**다. 모델 비교는 보조 축이며 학습은 필수 조건이 아니다. 판매 증가·광고 원인·시장 전체 유행·리뷰 분석은 이번 핵심 비교에 넣지 않는다.

## 2. 정답과 자료

| 구간 | 정의 |
|---|---|
| 기준 | 앞선 7개 관측일 평균 순위 R_B |
| 상승 감지 | 다음 7개 관측일 평균 순위 R_D |
| 확인 | 판단 이후 7개 관측일 평균 순위 R_H, 모델에는 숨김 |

후보는 R_B−R_D ≥ 10이다. 지속은 R_B−R_H ≥ 0.5×(R_B−R_D), 그 외는 소멸이다. 80위→40위라면 후속 평균 60위 이내가 지속이다. **달력상 7일이 아니라 수집된 7개 관측일**이다. 목록 부재에 대입하는 101은 실제 101위 관측이 아니다.

개발 자료는 2026-10-12의 맨투맨 8상품·7브랜드이며 색상 변형 2건을 포함한다. 당시 가용 데이터 버전은 보장되지 않아 과거 자료로 판단 시점을 모사한 실험이다. 기존 커머스 139건의 확장 비교도 한 시점의 후향적 비교이며, 검색 지수 벤치마크와 합산하지 않는다.

## 3. 비교 설계와 구현

| 비교군 | 입력 또는 방법 | 이번 상태 |
|---|---|---|
| A 정적 상태 | 상품 정보·현재 순위 | 입력 생성·누수 검사 완료, 유료 호출 없음 |
| B 원시 시계열 | A + 이전 14개 관측일 순위 | 입력 생성·누수 검사 완료, 유료 호출 없음 |
| C 계산된 근거 | B + 기준/감지 평균·상승폭·관측 범위 | 두 모델 각각 8건 실행 완료 |
| 고정 기준선 | 전부 지속 / 전부 소멸 | 계산·채점 완료 |
| 시계열 기준선 | 마지막 순위 유지 / 최근 3개 평균 유지 | 계산·채점 완료 |

B−A로 과거 흐름의 효과, C−B로 계산·정리의 효과를 검토하도록 설계했다. A의 본문에도 변화량이 남지 않도록 허용된 입력을 다시 만들고, B와 C는 동일한 원시 순위를 사용한다. 이번은 C만 실행했으므로 RQ1·RQ2 효과가 입증됐다고 쓰지 않는다.

## 4. 실제 실행 설정

| 항목 | Claude | A40 |
|---|---|---|
| 모델 | Sonnet 5.5 | Qwen3-8B, BF16, 학습 없음 |
| 추론 설정 | effort low, temperature 미지정 | thinking 켬, temperature 0.6, top_p 0.95, top_k 20 |
| 최대 출력·제한시간 | 8,192토큰·300초 | 8,192토큰·300초 |
| 실제 실행 | 8회, 재시도 0회 | 8회, 재시도 0회 |
| 실행 결과 | 유효 출력 8건 | 유효 출력 8건 |

같은 사례·질문·출력 형식을 사용한다. WATCH=지속 예측, NOT_SUPPORTED=소멸 예측, HOLD=보류다. 요약·지지 근거·반대 근거·부족한 정보를 저장한다. 근거 ID 오류, 응답 잘림, API 실패는 HOLD로 바꾸지 않는다.

입력·실행·평가 검사 75개와 기존 관련 회귀 검사 79개, 총 **154개 테스트**가 통과했다. 구현체는 기존 사이트 없이 실행할 수 있다.

## 5. 예비 수치 결과

전체 N=8, 실제 지속 4건·소멸 4건이다. 예측을 해시로 봉인하고 공개 예측 커밋을 남긴 뒤, 기존 139건 정답 봉인과 해시가 일치함을 확인해 채점했다.

| 방법 | 정답/오답/보류/실패 | 답변율 | 답한 사례 정확도 | 지속 적중률 | 지속 재현율 |
|---|---:|---:|---:|---:|---:|
| 전부 지속 | 4 / 4 / 0 / 0 | 100% | 50% | 50% | 100% |
| 전부 소멸 | 4 / 4 / 0 / 0 | 100% | 50% | — | 0% |
| 마지막 순위 유지 | 7 / 1 / 0 / 0 | 100% | 87.5% | 100% | 75% |
| 최근 3개 평균 유지 | 4 / 4 / 0 / 0 | 100% | 50% | 50% | 75% |
| Claude · C | 6 / 1 / 1 / 0 | 87.5% | 85.7% (6/7) | 100% | 50% |
| Qwen · C | 0 / 1 / 7 / 0 | 12.5% | 0% (0/1) | 0% | 0% |

정답·오답·보류·실패의 분모는 전체 8건, 정확도의 분모는 답한 사례만이다. —는 계산할 분모가 없다는 뜻이다. Claude는 마지막 순위 기준선과 오답 수가 같고 정답 수는 하나 적었다. Qwen은 대부분 보류했으며, 0/1만으로 일반적인 모델 능력을 판단하지 않는다.

|---|---|---:|---:|---:|
| Claude | 지속 | 2 | 1 | 1 |
| Claude | 소멸 | 0 | 4 | 0 |

## 6. 비용·실제 출력·실패 기록

Claude는 요청당 평균 6.76초, 사용량 기준 $0.101140이다. Qwen은 요청당 평균 39.88초이며, 준비·대기 포함 GPU 임대는 약 14분 46초로 약 $0.148로 추정했다. **API+GPU 계산액은 약 $0.249**다. 최종 청구서 금액이 아니며 Global volume 보관·IOPS 비용은 별도다. 예산 여유분 $0.50은 실제 사용액으로 더하지 않았다.

처음의 A40가 점유 중이라 Runpod 자동 이전으로 같은 A40를 확보했다. 실행 후 **기존·이전된 Pod 모두 중지, GPU 요금 시간당 $0.00 표시**를 확인했다. 가중치는 보관되어 저장 비용은 계속될 수 있다. 승인 범위인 총 $5·Claude $2·A40 2시간 안에서 진행했다.

고정 목록 첫 사례 2816996의 실제 출력 일부다. 성능을 보고 예시를 고르지 않았다.

**Claude — WATCH, 지지 근거 원문:**

> 기준 평균 56위에서 감지 평균 41.29위로 14.71계단 개선됐다. 최소 개선폭 10을 넘고, 지속 기준은 이후 평균 48.64위 이하다.

**Qwen — HOLD, 요약 원문:**

> 확인 기간 데이터 부재로 판단 불가

Qwen의 보류 7건은 미래 실제 관측이 없다는 점을 주요 이유로 들었다. 미래를 숨긴 것은 의도된 실험 조건이므로, 후속 개발에서는 예측과 사후 확인을 구분하는 지시와 보류 기준을 점검할 필요가 있다. 이번 출력은 바꾸거나 다시 호출하지 않았다.

설명 내용의 AI 보조 점검에서는 Claude의 근거 객체 34개 중 구간·개수 오류 3개와 필요조건 과장 2개, Qwen의 6개 중 문턱·미래 평균 혼동과 수치 비교 문제가 있는 1개를 확인했다. 사람 평가자 점수나 완전한 오류율이 아니다. 발언량이 달라 5/34와 1/6으로 모델 순위를 매기지 않는다. 잘못된 근거 ID는 모두 0개였지만, ID 일치만으로 설명이 정확해지는 것은 아니었다.

## 7. 논문에 무엇을 넣고 다음에 무엇을 하나

논문은 **문제와 관련 연구 → 자료·정답 → 방법·비교군 → 맨투맨 예비 결과 → 한계·후속 평가** 순서로 작성한다. 이번 성과는 방법론과 평가 체계의 확정, 두 모델 및 단순 기준선의 초기 수치·보류·오류 확인이다.

같은 사례에서 C가 B보다 전체 오답 비율을 높이지 않으면서 정답 처리 비율을 높이면 개선을 지지하는 결과로 해석한다. 한 지표만 좋아지면 상충 관계로 보고한다. 임의의 80% 목표, 한 시점의 통계적 우위, 시계열을 넣었다는 사실 자체의 신규성은 주장하지 않는다.

후속에는 공통 지시와 보류 기준을 점검해 다시 고정하고, 개발에 사용한 이 상품군을 제외한 기존 상의 A/B/C 후향적 비교를 수행한다. 이후 겹치지 않는 새 시점의 관측 창으로 검증한다. 같은 상품·색상 변형을 식별하고 검색 지수 결과와 합산하지 않는다. 이번 예산으로 후속 호출하지 않았다.

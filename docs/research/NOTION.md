# 트렌드 추론 · 1차 스펙과 Qwen 동작 확인

작성일 2026-11-08 · 현재 버전 forecast-v2 · 이번 주: 환경과 1차 스펙 확정

**현재 상태: 실행 환경 준비 완료 / 예측·보류 기준 확정 / Qwen 동작 검증 미통과.**

같은 맨투맨 8건을 Qwen으로 다시 실행했다. 원문에서 과거 근거로 미래를 예상한 것은 3건이고, 그중 출력 형식까지 유효한 것은 2건이었다. 5건은 미래 실제값이 없다는 점을 판단 중단이나 반대 근거로 사용했다. 이번 숫자는 정답률이 아니라 요청한 과제를 수행했는지 점검한 기록이다.

## 이번에 결정한 1차 범위

- **대상:** 맨투맨 8상품. 현재 확보된 과거 순위로 상승 지속성을 예상하는 흐름을 확인한다.
- **입력:** 판단 시점 이전 14개 관측일의 순위와 코드가 계산한 평균·상승폭·판정 문턱. 미래 실제값은 넣지 않는다.
- **모델 역할:** 이후 수집이 있는 7개 관측일에도 상승분 절반 이상이 유지될지 예상하고, 과거 근거와 한계를 설명한다.
- **출력:** WATCH / NOT_SUPPORTED / HOLD, 짧은 요약, 지지·반대 근거와 근거 ID, 부족한 과거 정보.
- **이번 확인:** 모델이 미래값을 기다리는 대신 예측하는지, 문턱과 근거를 제대로 사용하는지 확인한다.

정식 연구 질문·비교 실험·논문 결론은 이후 결정한다. 이번 결과로 Qwen의 일반적인 성능이나 시계열 결합 효과를 판단하지 않는다.

## 예측과 보류 기준 — v2 확정

**WATCH:** 과거 자료에서 상승분 절반 이상 유지 쪽이 더 지지된다는 예측.

**NOT_SUPPORTED:** 과거 자료에서 그 기준 미달 쪽이 더 지지된다는 예측. ‘판단할 수 없다’의 대체 표지가 아니다.

**HOLD:** 다음 중 하나를 구체적으로 설명할 수 있을 때만 허용한다.

- 필요한 과거 순위·시점이 없거나 손상·모순되어 흐름을 해석하기 어렵다.
- 과거 관측의 한계나 서로 반대되는 신호를 대조해도 어느 방향이 더 지지되는지 정하기 어렵다.

미래 실제값이 없거나 100% 확신이 없다는 이유만으로 보류하지 않는다. 광고·리뷰 등 이번 범위 밖 정보가 없다는 이유만으로도 보류하지 않는다. 대신 실제 과거 근거와 왜 방향을 정하기 어려운지 적는다.

**판정 문턱은 평가 기준이다.** 미래의 관측값이나 이미 산출된 예측값이 아니다. 예측을 설명하기 위해 미래 순위 숫자를 새로 만들 필요도 없다. 목록 부재에 쓰는 101은 실제 순위가 아닌 계산 경계값이다.

## 같은 8건을 어떻게 다시 확인했나

기존 v1 자료·상품·사용자 입력 문자열과 모델 설정을 유지하고 시스템 지시만 v2로 교체했다. 8건의 입력 일치를 검사했으며, 수정 프롬프트와 점검 기준은 호출 전에 저장했다.

Qwen3-8B / A40 / BF16 / thinking 활성 / temperature 0.6을 유지했다. 실제 요청은 Qwen 8회, 재시도 0회이며 Claude 추가 호출은 없다. 기존 v1 결과를 덮어쓰지 않았고 이번에는 정답 파일을 읽거나 정확도를 다시 채점하지 않았다.

## 동작 확인 결과

| 확인 항목 | 건수 |
|---|---|
| 응답 수신·정상 종료 | 8/8 |
| JSON·근거 ID 검사 통과 | 5/8 |
| 원문에서 과거 근거로 예측 | 3/8 |
| 예측 수행과 형식 검사 모두 통과 | 2/8 |
| 미래값 부재를 판단 중단·반대 근거로 사용 | 5/8 |
| 없는 근거 ID 사용 | 3/8 |
| 문턱을 미래 평균으로 치환 | 0/8 |

항목끼리 겹치므로 건수를 더하지 않는다. 원문 판정은 WATCH 3건·NOT_SUPPORTED 3건·HOLD 2건이지만, 이 표지만으로 과제를 수행했다고 인정하지 않았다. 출력 내용을 입력과 대조한 AI 보조 점검이며 사람 평가자 합의 결과나 예측 정확도가 아니다.

**예측한 사례 — 4130049:** 과거 평균 순위 52위에서 29.29위로 개선된 점을 근거로 “상승세가 지속될 가능성이 있음”이라고 답했다. 다만 최근 악화한 순위 등 반대 흐름 검토는 부족했다.

**표지는 예측이지만 내용은 판단 중단 — 4216006:** NOT_SUPPORTED를 냈으나 실제 요약은 “예측 기준에 필요한 미래 평균 순위 데이터가 부재하여 지속 여부 판단 불가”였다. 소멸을 예측한 응답으로 인정하지 않았다.

**예측했지만 형식 오류 — 4205647:** 과거 순위로 WATCH를 설명했으나 허용되지 않은 근거 ID인 history를 사용했다. 원문의 예측 의도는 확인했지만 유효한 결과로 채택하지 않았다.

## 실행 환경·비용·종료

A40 재시작 때 기존 GPU를 사용할 수 없어 같은 사양으로 이전했다. 저장된 모델 파일 연결 문제는 같은 revision의 가중치를 검증해 임시 캐시에 복구했다. 모델 버전·주요 패키지·추론 설정은 기존과 일치했으며 환경 차이는 기록에 남겼다.

- 관련 코드 검사 82개 통과. 버전별 실행 분리와 재시도 금지 포함.
- 이번 GPU 약 19분 22초, 비용 추정 약 $0.194. 준비·복구·대기 포함.
- 기존 실행 포함 GPU 약 34분 8초, API·GPU 추정 합계 약 $0.443.
- 저장·IOPS는 별도다. $0.50 여유분을 더한 계산도 약 $0.943으로 기존 총 $5 안이다. 여유분은 실제 지출이 아니다.
- 모든 Pod의 중지 상태와 시간당 $0.00을 확인했다. 최종 청구서가 아닌 시간 기반 비용 추정이다.

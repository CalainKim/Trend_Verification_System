# 9주차 주간보고 (2026-10-28 ~ 11-01)

연계 산업체  무신사
학번 성명  202220697 김도은 (수집 파트)
지도교수  윤대균 교수님

## 1. 요약

중간보고서 시점의 최대 문제는 검증 대상 사례가 1건에 머물러 실험 자체를
수행하지 못한 것이었다. 사례를 고르려면 선정 기준을 먼저 합의해야 하는데
그 합의가 3주째 진행되지 않았다.

이번 주에 이 병목을 우회하는 방법을 찾았다. 묻는 질문을 "이 후보가 진짜
유행인가" 에서 "이 상승이 얼마나 버티는가" 로 바꾸면 정답을 사람이 정하지
않아도 된다. 자료가 답하기 때문이다. 그 결과 사례가 1건에서 229건으로 늘었고
처음으로 채점이 가능해졌다.

함께 산업체가 제시한 가설 하나를 자료로 검증했고, 지지되지 않는다는 결과를
얻었다.

## 2. 질문을 바꾼 이유

원인은 외부에서 관측할 수 없다. 어떤 상품의 순위가 오른 이유가 실제 수요인지
광고인지 노출 알고리즘인지는 쇼핑몰 내부 정보이고 크롤링으로 알 수 없다.
실제로 순위가 10계단 이상 오른 379건 중 66%는 수집 가능한 어떤 변수로도
설명되지 않았다.

그런데 수명은 볼 수 있다. 광고로 올린 순위는 광고가 끝나면 떨어지고 그
떨어짐은 밖에서도 관측된다. 원인을 묻는 대신 수명을 물으면 관측 불가능한
문제가 관측 가능한 문제가 된다.

정답도 자료에서 나온다. 관측 구간에서 오른 것을 찾고 확인 구간에서 상승분의
절반이 남았는지를 보면 된다. 연구자의 판단이 들어가지 않으므로 선정 편향이
생기지 않고, 수집이 이어지는 만큼 사례가 자동으로 늘어난다.

## 3. 한 일

### 3.1 상품명에서 속성 키워드 추출

커머스는 상품 하나를, 검색 API 는 품목 키워드를 다룬다. 두 채널의 키가 서로
다른 문자열이어서 교차 검증이 가능한 후보가 444건 중 3건뿐이었다.

상품명 2,189개에서 속성을 뽑아 단위를 맞췄다. 커버리지 99.5%, 속성 74종이다.
사전은 사람이 검수하는 파일로 코드 바깥에 두었다.

### 3.2 지속성 벤치마크 세 종

    대상           확인 기간   사례    기저율
    29CM 순위        7일      61건   54.1%
    검색 지수 한국    28일      60건   68.3%
    검색 지수 3개 지역 84일     108건   48.1%

기저율은 아무 판단 없이 전부 "지속" 이라고 답했을 때의 정확도다. 지표의
성질과 확인 기간이 달라 47%에서 74%까지 벌어지므로 셋을 합쳐 하나의 점수로
내지 않는다.

문제지에는 정답을 넣지 않는다. 정답은 별도 파일에 두고 저장소에서 제외하며
봉인 해시만 남긴다. 특징을 만드는 함수와 정답을 만드는 함수가 받는 자료를
아예 분리해 누수를 구조로 막았다.

### 3.3 판정 채점기

검증 파트가 판정을 내면 기저율보다 나은지를 재는 도구다.

정확도만 보고하면 찍은 것과 같은 점수를 성과로 읽게 되므로 항상 기저율과
함께 낸다. 보류는 오답이 아니라 답하지 않은 것이므로 커버리지를 따로 세고,
기저율도 답한 부분집합에서 다시 계산한다. 정답이 지속인 사례만 골라 답하면
정확도 100%가 나오지만 그 부분집합의 기저율도 100%이므로 기저율을 넘지
못한 것으로 집계된다.

유의성은 정확도 신뢰구간의 아래끝이 기저율을 넘는지로 본다. 모의 판정으로
확인한 결과 정확도 64.2%가 기저율 54.7%보다 9.4%p 높아도 61건으로는
통계적으로 구별되지 않았다.

### 3.4 산업체 가설 검증

산업체는 "유행은 주로 해외에서 한국으로 온다" 는 가설로 감지를 시도했고
노이즈가 너무 많다고 했다. 구글 트렌드 8개 속성을 5년치로 조회해 한국과
미국의 검색 지수 시차를 측정했다.

    헨리넥    -21일      스트라이프  -14일
    코튼     -28일      레이어드    -49일
    블라우스  +14일

신뢰 가능한 5건 중 4건에서 한국이 먼저 움직였다. 가설과 반대 방향이다.
분석 구간을 365일에서 1500일까지 바꿔도 결과가 21일 이내로 일치했다.

다만 표본이 5건이고 계절성을 분리하지 못했으므로 일반화할 수 없다. 조사한
품목군과 기간에서 지지되지 않았다고만 쓸 수 있다.

## 4. 검증되지 않은 가설

세운 가설 중 둘이 자료의 지지를 받지 못했다. 그대로 기록한다.

가설 1. 할인으로 오른 순위는 금방 사그라진다.
  할인이 늘었던 상승 57.1% 유지, 변화 없던 상승 52.9% 유지로 차이가 없었다.

가설 2. 한 브랜드의 여러 상품이 동시에 오르면 광고다.
  동시 상승 62.5% 유지, 단독 상승 51.5% 유지로 오히려 반대였다. 브랜드 자체가
  뜨는 것도 트렌드일 수 있다는 뜻이고, 분석 단위에 브랜드를 추가했다.

본 과제의 평가 기준이 정확도가 아니라 절차의 투명성이므로 틀린 가설도
산출물에 남긴다.

## 5. 막혀 있는 것

구글 트렌드가 연속 24회쯤 요청하면 IP 단위로 차단하고 몇 시간 뒤에 푼다.
한 번에 몰아 받는 방식으로는 사전의 55개를 채울 수 없어 시간별 증분 수집으로
바꿨다. 이미 받은 것은 건너뛰고 막히면 재시도 없이 즉시 끝낸다.

11월 1일 매시 17분 실행으로 등록해 가동 중이다. 첫 실행에서 8개를 받아
6,072행이 들어왔고 현재 18개를 확보해 37개가 남았다.

## 6. 다음 주 예정

1. 구글 트렌드 55개 수집 완료. 자동 수집이 가동 중이므로 며칠 안에 채워진다.
   전부 받으면 주 벤치마크가 190건쯤 되어 기저율 대비 10%p 개선까지
   통계적으로 주장할 수 있다.
2. 최초 기획과 실제 구현의 차이 정리. 이번 주에만 가설 두 건이 뒤집혔고
   설계 결정이 여러 번 바뀌었다.
3. 검증 파트와 번들 형식 확인. 채점기까지 맞물리는지 실제 판정으로 검증한다.

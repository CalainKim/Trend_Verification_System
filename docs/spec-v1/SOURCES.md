# 근거와 범위 결정

## 이번 범위의 우선순위

2026-11-03 사용자는 **실질적인 문제 상황, 해결 방법론, 어느 정도 해결했는지로 1차 MVP를 정리**하고, 추가 리뷰를 빼고 **트렌드 탐지 과제에만 집중**하도록 지정했다. 이 지시가 이전 통합 검증·모델 비교 문서보다 우선한다.

| 출처 | 사용할 내용 | 사용하지 않을 해석 |
| --- | --- | --- |
| 사용자 제공 트렌드 과제 해설 | 흩어진 온라인 패션 신호, 단발 노출과 시장 반응을 구분하기 어렵다는 문제 맥락 | 회사 직접 발언·확정 인터뷰 답변, 예시 확률/정확도 |
| 협업 진행 대화 | SNS 수집 제약, 인터뷰 수행 보고, 기존 모델·수집 작업 존재 | 인터뷰의 실제 기준값이나 완료된 데이터 인계 |

첨부된 자료는 해설문이다. 현재 확인 범위에서 원 인터뷰 전사문과 확정된 문답표는 확보되지 않았다. 인터뷰 원문이 추가되면 **트렌드 탐지 팀의 문답만** 문제–방법–기능에 연결한다. 다른 팀의 과제와 일반적인 엔지니어 역할론은 이 스펙의 요구사항 근거로 사용하지 않는다.

## 기존 내용에서 정리한 부분

- “후보 검증만 주 기능”이던 문서를 최신 요청에 맞게 후보 탐지 중심으로 바꿨다.
- 로컬/상용 모델 비교·사람 리뷰·후속 정답 평가를 필수 단계에서 뺐다.
- 기존 범위였던 한국 20대 남성과 현재 수집된 남녀 상의 자료를 구분했다.
- 브랜드 수·상승·지속 규칙은 코드의 시험 정책으로 명시했다.
- 점수와 확률을 구분하고 근거 없는 해결률을 쓰지 않았다.
- 최신 main의 구현을 기준으로 작성했으며, 별도 로컬 작업 폴더의 검증 패키지는 보존했다.

개인 대화 원문, 인터뷰 개인정보, 비밀키와 원시 API 응답은 공유 문서나 PR에 포함하지 않는다.
